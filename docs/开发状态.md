> 更新日期:2026-08-13
> 规格来源:插件仓库 `ai-auto-form/docs/用户系统后端技术方案.md`(v3)。本文档记录后端的实际完成度:做了什么、怎么做的、还差什么。改代码后请同步更新本文档。

## 一、项目定位

AI 智能录入助手(浏览器插件)的用户与计费后端:账号、订阅积分、易支付、统一 AI 网关(12 个业务能力接口)、Web 控制台。

- **建设方式**:"搭积木"——订阅桶模型/易支付流程/SMTP 模式/前端形态取自 [new-api](https://github.com/QuantumNous/new-api)(AGPL-3.0,署名义务见 [NOTICE.md](../NOTICE.md));AI 网关、积分流水、任务预占、请求幂等为本项目自建。
- **许可证**:AGPL-3.0 整仓开源。提示词、密钥、限流阈值等属私有运行时配置,不入仓库。

## 二、架构与目录

```text
浏览器插件 / Web 控制台(web/,React + 自建 UI 层,embed 进二进制)
        │ HTTPS  Bearer accessToken
┌───────┴────────────────────────────────────────┐
│ Go 单体(Gin + GORM)                             │
│  auth 认证 │ subscription 订阅 │ credits 积分    │
│  ai 网关(幂等/计费/上游切换) │ payment 易支付      │
│  server 路由/管理接口 │ ratelimit │ email        │
└──────┬─────────────────────────┬───────────────┘
   PostgreSQL(开发用 sqlite)   N 个 OpenAI 兼容上游(库内配置,顺序切换)
```

| 目录 | 内容 |
| --- | --- |

## 三、已完成

### 3.1 认证与账号

- 邮箱验证码登录(免密,首登即注册):HMAC(pepper) 存储、同码验错 5 次作废、新码作废旧码、验证+消费原子;同邮箱 1 分钟 1 条/日 10 条、每 IP 每小时 20 次。
- **可选密码登录**:验证码是身份根(注册/找回),密码是快捷方式;`set-password`(≥8 位,bcrypt)需登录态;按邮箱+IP 双限流防爆破;错误不暴露账号存在性。
- JWT access(30 分钟) + refresh 旋转:旧 token 不删(`revoked_at/replaced_by/family_id`),超 30 秒宽限期复用视为泄露撤销整个 family;并发刷新原子防分叉。
- `ADMIN_EMAILS` 引导管理员(登录时自动升 admin,角色存库)。

### 3.2 订阅与积分

- 套餐 = **独立月度额度桶**,到期只改状态、历史账目不动;注册自动发 14 天 100 分试用桶;默认套餐 9.9 元/1000 分、59.9 元/10000 分,管理台可改(只影响新订单)。
- `available = Σ(active 桶剩余) − Σ max(hold.amount − consumed, 0)`;扣费先扣最早到期桶,可跨桶拆扣;流水只增不改,带能力单价快照与余额快照。
- 任务预占:创建(`available` 校验+同任务幂等)、心跳续期(2h 租约/10min 心跳)、结算(原子幂等无流水)、过期自动释放;支持超预占(等同散调逐笔校验)。
- 能力单价表 `capability_prices`:12 个能力的积分单价 + 模型/温度/maxTokens,管理台即改即生效,在途请求与已建预占按快照。

### 3.3 AI 网关(12 个能力接口)

- 与插件 `utils/ai.ts` 一一对应;严格 JSON 解码(未知字段拒绝)+ 逐字段行/列/长度上限 + 256KB 请求体上限。
- **幂等状态机**:`(user_id, request_id)` 唯一索引原子插入 pending + 90 秒租约;缓存命中直接重放;租约过期可抢占接管;缓存 24h 清除后返回 410 绝不重调重扣;扣费与状态落定同事务。
- **表单识别计费组**:`billingGroupId` 打包 assess/analyze/pick-open,计费事件=analyze_form 成功,数据库部分唯一索引保证一组一条流水。
- 输出解析容忍围栏/废话,幻觉 selector/列名/字段序号服务端过滤(插件端仍保留最后防线);不合规同链重试 1 次,仍失败 422 不扣分。
- 提示词:`prompts/private/<capability>.yaml`(version/system/user,Go text/template),已从 ai.ts 完整移植 12 个;版本号写入每条请求记录。

### 3.4 AI 上游(数据库管理,无写死厂商)

- `ai_upstreams` 表:任意多个 OpenAI 兼容端点,管理台增删改,**密钥即改即生效不需重启**。
- 故障切换:按优先级升序尝试(网络错/超时/429/5xx/401/403 换下一个);连败 3 次冷却 60 秒被跳过;连接 5 秒/整体 60 秒超时;切换不重复扣分;`ai_requests` 记录实际服务的上游与 token 用量。

### 3.5 支付(易支付)

- 下单(套餐校验/订单落库/收银台跳转参数)、异步通知与同步返回(验签 + 金额一致性 + 状态守卫幂等发桶,重复回调安全)。流程移植自 new-api,依赖 go-epay。

### 3.6 Web 控制台(`web/`,embed 单二进制)

- 登录页:验证码/密码双 Tab,发送冷却倒计时。
- 用户侧:个人中心(可用积分/订阅桶/设密码)、购买套餐(套餐卡片→易支付表单跳转→回跳 `?pay=` 提示并刷新)、积分流水(能力中文名/游标分页)。
- 管理侧(菜单仅 admin 可见):套餐管理、能力配置、AI 上游、用户管理(封禁即撤销全部 refresh token 全端登出)。
- 401 自动用 refresh 换新重试;SPA 回退由后端托管;页脚含 AGPL 源码链接与 new-api §7 署名。

### 3.7 其他

- 后台任务(每分钟):订阅过期、预占过期释放、幂等缓存 24h 清理。
- 限流:AI 每能力 60 次/分、每人 5000 次/日;发码与密码尝试独立限流;单实例内存实现。
- `/v1/about`:源码地址与署名(AGPL §13)。
- 数据最小化:业务原文只在内存转发,唯一短暂落盘是幂等缓存里的 AI 输出(24h);访问日志不记 body。
- **测试 23 个用例全过**(sqlite 内存库):预占数学(1000/530/10→470)、跨桶扣费、计费组防重、超预占、余额不足/无订阅、过期桶排除、hold 生命周期、验证码锁定/新码废旧码、密码全流程、refresh 旋转/宽限/泄露检测、上游切换/冷却/全挂、网关幂等重放/410/422 不扣分/幻觉过滤。

### 已知取舍(有意为之,不是遗漏)

- 开发环境 `DB_DSN` 留空走 sqlite,生产必须 Postgres(行锁语义依赖它)。
- SMTP 未配置时仅开发模式把验证码打进控制台日志,生产模式直接报错(不静默降级)。

- 单二进制整体 AGPL 开源,自建模块不例外;竞争对手可合法部署——护城河不在这份代码里。
